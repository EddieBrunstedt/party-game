# 0005: Start on Bevy 0.20

**Status:** Accepted (2026-10-20)

## Context

Bevy 0.20 was released 2026-10-08. Several ecosystem crates still target 0.19: `bevy_ggrs`, `bevy-steamworks`, `bevy_hanabi` and `bevy_skein` as released versions.

## Decision

Start on Bevy 0.20.

## Why it's safe

- Rollback (`ggrs`) and Steam (`steamworks`) are used directly and don't depend on Bevy (ADRs 0002 and 0004). The lagging wrappers aren't needed.
- `bevy_hanabi` and `bevy_skein` already have 0.20 ports on their main branches. Use git dependencies until they release.
- `leafwing-input-manager`, `bevy_enhanced_input`, `bevy_kira_audio`, `avian3d` and `bevy_rapier3d` already support 0.20.
- Simulation crates don't depend on Bevy (ADR 0001), so future Bevy upgrades only touch the `game` crate.

## Consequences

Git dependencies have to be swapped for released versions once those versions exist.
